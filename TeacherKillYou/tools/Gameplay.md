# ポーズ 設定 チェックポイント

- ゲーム中の **Esc** でポーズ。敵、移動、回復、リロード、BGM、環境音、SEを一時停止する。
- ポーズ画面は上下キーとEnter、またはマウスで操作する。
- 「画面・音量・マウス設定」では、BGM、環境音、SEを個別に調整できる。マウス感度は初期値に対する0.1〜3.0倍。
- スライダーはドラッグか左右キーで調整する。「保存して戻る」またはEscで設定を保存する。
- 「画面の明るさ」は50〜200%。100%が従来の見え方で、上げると暗い部分が見やすくなる。
- 「緑の強さ」は0〜100%。100%が従来の緑で、下げるとライト・霧・周囲のぼかしを中性色へ寄せる。
- 表示補正は即座に反映する。設定中は背景が見えるため、プレイ画面を見ながら調整できる。
- 表示設定も各PCの `Data/Save/settings.json` に保存され、他のPCにはGit経由で共有されない。旧設定には100%を補う。
- ウィンドウが操作対象から外れた場合も自動でポーズする。

## チェックポイント

ポーズ画面の「チェックポイントを保存」で、その時点の進行を1枠に保存する。会話中、暗転中、死亡中、System Camera使用中は保存できない。
テレポートが完了して暗転が解けた時にも自動保存する。

次の場所から保存地点へ戻れる。

- ポーズ画面の「チェックポイントから再開」
- タイトル画面のCキー
- 死亡画面の「チェックポイントから再開」またはCキー

タイトルのSpaceと死亡画面のRは、従来どおり最初から開始する。新規開始だけでは、以前のチェックポイントを上書きしない。

保存するのは位置、向き、HP、スタミナ、弾薬、所持品、取得済みアイテム、残っている敵の位置とHP、ドア、ライト、マップ配置。
ロード時は進行中の攻撃、回復、リロード、暗転、血や弾痕などの一時的な演出を解除する。倒した敵は復活しない。

`Data/Save/checkpoint.json` が進行、`Data/Save/settings.json` が設定。どちらもGit管理の対象外で、配置編集用の `scene.json` とは別。
ファイル全体を検証してから復元するため、保存が壊れていてもプレイ中の状態には適用しない。
ファイルの一時書き込みが成功した後で既存の保存を置き換える。

## 音源の差し替え

`Data/Audio/README.md` を参照。今回の足音・唸り・リロード・環境音は、ゲームを動かして調整するための仮音。
音源を差し替えて再起動すれば、プログラムの修正なしで使用できる。

## Debug専用の確認メニュー

`Debug / x64` で起動し、プレイ中に `Esc → デバッグ` を選ぶと開きます。Releaseにはこのボタンは表示されません。
確認中は敵・移動・攻撃・回復などの進行が止まり、背景へ調整結果が反映されます。Escまたは「Escメニューに戻る」でポーズ画面へ戻り、さらにEscでプレイを再開します。

- **ブラー・画面**：ブラーON/OFF、ライトの外側／画面端／全画面、強さ0〜100%、半径0〜16px。OFF・弱め・従来のプリセットで比較できます。
- **画面効果**：グローとフィルムノイズのON/OFF・強さ、明るさ・緑、懐中電灯、画面効果前の表示とライトの照射マスク。
- **描画・診断**：1080p上限の切り替え、内部描画倍率50〜100%、ウィンドウ／フレームバッファ／内部描画の解像度、FPS・フレーム時間・DPI。上限OFF・100%では画面の実ピクセル数で描画するため負荷が増えます。
- **状態確認**：プレイヤーの位置・体格・HP・スタミナ・残弾、敵の数と各HP・行動状態、モデルのメッシュ数とボーン数。
- **確認用の表示**：FPSと内部解像度の常時表示、当たり判定ワイヤー、テレポート／ゴール範囲の表示。

「Debug設定を保存」で `Data/Save/debug_graphics.json` に保存し、次のDebug起動から読み込みます。Gitの共有対象外で、Releaseは読み込みません。比較用の照射マスクは再起動時に完成表示へ戻します。
「画面効果を初期値に戻す」は従来のブラー75%・半径6pxなどへ戻します。明るさと緑は通常のプレイヤー設定としてゲームへ戻る時に保存します。
System Cameraでは従来どおり明るい編集表示になるため、ブラー・画面効果の比較にはPlayer Cameraを使ってください。

## Debugの戦闘・位置確認

`Esc → デバッグ → 戦闘・位置` から使用します。Releaseには表示されません。

- **敵の条件確認**：索敵・追跡解除・攻撃範囲、向き、直前の移動要求と実移動を表示します。実際の攻撃可否と、距離・向き・高さ・壁・ドアの理由、クールダウン、被弾反応を確認できます。索敵は距離に加えて壁・ドアによる遮蔽を判定し、視認状態・最後に見た位置・捜索残り時間・行き詰まりも表示します。
- **射撃確認**：実際に使ったカメラの射線と命中点を直近8発表示し、最新32発の命中対象・敵ID・実ダメージ・残HPを記録します。履歴は開始・リセット・チェックポイント読み込み時に消去します。
- **補充と確認用設定**：HP・スタミナの全回復、マガジン・予備弾の補充、無敵・無限弾。無敵・無限弾は保存されず、新規開始・チェックポイント読み込み時にOFFへ戻ります。有効な間はプレイ画面に表示します。
- **テスト位置5枠**：現在位置と向きを登録して戻れます。床への補正は切り替え可能です。HP・所持品・敵の状態は移動操作で変更しません。ステージの移動・拡縮後は古い位置を使わず再登録します。

範囲・射線の表示と登録位置は「Debug設定を保存」で既存の `Data/Save/debug_graphics.json` に保存できます。通常の進行保存とは別で、無敵・無限弾や射撃履歴は保存しません。

## 敵の索敵と追跡

- 索敵範囲にいても、ステージの壁やドアで胴・頭への視線が遮られる場合は発見しません。視線判定は敵ごとに0.1秒間隔で行います。
- 視認中は追跡し、見失うと最後に見えた位置を最大3秒だけ捜索します。隠れたプレイヤーの現在位置を追跡には使用しません。
- 最後に見た場所へ到着すると停止し、再発見できなければ待機に戻ります。移動要求に対してほぼ進めない状態が0.75秒続いた場合も停止します。
- 同じ通れない位置へ毎フレーム再突進せず、相手の移動や見失った後の再発見で追跡を再試行します。移動時もドアの当たり判定を使います。
- Debugの「戦闘・位置」で視認、捜索残り時間、行き詰まりを確認できます。範囲表示をONにすると視線と最後に見た位置も描画します。
