# TeacherKillYou

raylibを使用した学校脱出ホラーゲームです。Visual Studioで `TeacherKillYou.sln` を開き、x64のDebugまたはReleaseでビルドします。
起動時の作業フォルダは、このREADMEと `Data` があるプロジェクトフォルダです。

## ソースの配置

`main.cpp` が起動入口です。ゲームの実装は `Source` にまとめ、同じクラスの `.h` と `.cpp` を同じ役割のフォルダへ配置しています。
ヘッダーに宣言、cppに実装を置きます。Visual Studioのフォルダ表示も実際の配置に合わせています。

| フォルダ | 内容 |
| --- | --- |
| `Source/Core` | ゲーム全体の状態、共通寸法、設定 |
| `Source/Scenes` | タイトル、プレイ、クリア、シーン遷移 |
| `Source/Actors/Player` | プレイヤーの移動、銃、HP、スタミナ |
| `Source/Actors/Enemy` | 敵のAI、移動、攻撃、アニメーション |
| `Source/World` | ステージ、ドア、テレポート、ゴール |
| `Source/Camera` | プレイヤー用・デバッグ用カメラ |
| `Source/Items` | アイテムとインベントリ |
| `Source/Audio` | BGM、SE、足音、環境音、敵の唸り |
| `Source/Graphics` | ライト、画面効果、血のエフェクト |
| `Source/Resources` | モデル、マテリアル、FBXとアニメーションの読み込み |
| `Source/UI` | 日本語フォント、会話、ポーズ、ゲームオーバー画面 |
| `Source/Save` | シーン配置、設定、チェックポイントの保存と読み込み |
| `Source/Debug` | ImGuiのデバッグ操作とギズモ |

`TeacherKillYou.vcxproj` の `GameIncludeDirectories` に、ゲーム用ヘッダーの検索先を定義しています。
既存の `#include "Player.h"` などはそのまま使えます。

## マップとキャラクターの大きさ

共通の寸法は [WorldScale.cpp](Source/Core/WorldScale.cpp) にあります。
値はこのマップのワールド単位で、メートル換算値ではありません。現行校舎の天井高約4.65を基準に、通路を通れる体格へ合わせています。

| 対象 | 高さ | 当たり判定の半径 |
| --- | ---: | ---: |
| プレイヤー | 2.90 | 0.36 |
| MONSTER | 3.10 | 0.42 |
| ゾンビ | 2.90 | 0.36 |

目線はプレイヤーの身長の91%です。敵のモデル表示と当たり判定は、同じ高さを参照します。
マップの描画倍率は1.25で、既存の配置を基準にキャラクターを合わせています。
変更前に作成したチェックポイントは、読み込み時に敵の寸法を移行してHPや所持品を引き継ぎます。

## データと外部ライブラリ

- `Data/Image`：マップ、キャラクター、銃、UI、テクスチャ。FBXと材質補助ファイルは同じフォルダで管理します。
- `Data/Audio`：BGM・SE。[音源の配置方法](Data/Audio/README.md)
- `Data/Font`：日本語フォント。
- `Data/Json`：会話データ。
- `Data/Save`：プレイヤー個人の設定と進行。Gitの管理対象外です。
- `scene.json`：配置編集用のシーンデータ。
- `imgui`、`imguizmo`、`rlImGui`、`nlohmann`、`third_party`、`packages`：外部ライブラリ。Visual Studioでは `External` に表示します。
- `tools`：素材の補助スクリプトと説明書。[ゲームの操作](tools/Gameplay.md) ／ [FBXの読み込み](tools/FBX.md)
- `build`、`x64`：検証用ファイルとビルド出力。

## 起動と読み込み

タイトルでは日本語フォントと音声を準備し、3D素材はゲーム開始後に進捗を表示しながら読み込みます。
タイトルへ戻って再開する場合、ResourceManagerのモデルとアニメーションは再読み込みしません。
進捗は素材の処理件数に基づき、残り時間ではありません。大きい素材の処理中は一時的に止まることがあります。
開発時にもFBX取り込みが遅くならないよう、Debug構成ではFBX取り込み用の2ファイルのみ最適化しています。
FbxLoader.cppとufbx.cのステップ実行では最適化の影響を受けます。ゲーム本体のDebug設定は従来どおりです。
実際に遊ぶ速度を確認する場合は、Visual Studioで `Release / x64` を選びます。
出力の `LOADING:` ログには、各素材の読み込みにかかった秒数が表示されます。

## 画面ごとの明るさと緑の調整

プレイ中に `Esc → 画面・音量・マウス設定` を開き、背景を見ながら調整します。
「画面の明るさ」は50〜200%、「緑の強さ」は0〜100%。両方100%が従来の見え方です。
相手の画面で暗すぎる場合は明るさを上げ、緑が濃すぎる場合は緑の強さを下げてください。
「保存して戻る」またはEscで保存します。設定は各PCの `Data/Save/settings.json` に保持され、Gitの共有対象外です。
既存の設定ファイルにも対応し、表示設定がない場合は100%を使用します。明るさの補正は3Dシーンだけに適用し、HUDとメニューは同じ明るさを保ちます。

## Debug専用の確認メニュー

`Debug / x64` で起動し、プレイ中に `Esc → デバッグ` を選ぶと開きます。Releaseにはこのボタンは表示されません。
確認中は敵・移動・攻撃・回復などの進行が止まり、背景へ調整結果が反映されます。Escまたは「Escメニューに戻る」でポーズ画面へ戻り、さらにEscでプレイを再開します。

- **ブラー・画面**：ブラーON/OFF、ライトの外側／画面端／全画面、強さ0〜100%、半径0〜16px。OFF・弱め・従来のプリセットで比較できます。
- **画面効果**：グローとフィルムノイズのON/OFF・強さ、明るさ・緑、懐中電灯、画面効果前の表示とライトの照射マスク。
- **描画・診断**：1080p上限の切り替え、内部描画倍率50〜100%、ウィンドウ／フレームバッファ／内部描画の解像度、FPS・フレーム時間・DPI。上限OFF・100%では画面の実ピクセル数で描画するため負荷が増えます。
- **状態確認**：プレイヤーの位置・体格・HP・スタミナ・残弾、敵の数と各HP・行動状態、モデルのメッシュ数とボーン数。
- **確認用の表示**：FPSと内部解像度の常時表示、当たり判定ワイヤー、テレポート／ゴール範囲の表示。

「Debug設定を保存」で `Data/Save/debug_graphics.json` に保存し、次のDebug起動から読み込みます。Gitの共有対象外で、Releaseは読み込みません。比較用の照射マスクは再起動時に完成表示へ戻します。
「画面効果を初期値に戻す」は従来のブラー75%・半径6pxなどへ戻します。明るさと緑は通常のプレイヤー設定としてゲームへ戻る時に保存します。
System Cameraでは従来どおり明るい編集表示になるため、ブラー・画面効果の比較にはPlayer Cameraを使ってください。

## Debugの戦闘・位置確認

`Esc → デバッグ → 戦闘・位置` から使用します。Releaseには表示されません。

- **敵の条件確認**：索敵・追跡解除・攻撃範囲、向き、直前の移動要求と実移動を表示します。実際の攻撃可否と、距離・向き・高さ・壁・ドアの理由、クールダウン、被弾反応を確認できます。索敵は距離に加えて壁・ドアによる遮蔽を判定し、視認状態・最後に見た位置・捜索残り時間・行き詰まりも表示します。
- **射撃確認**：実際に使ったカメラの射線と命中点を直近8発表示し、最新32発の命中対象・敵ID・実ダメージ・残HPを記録します。履歴は開始・リセット・チェックポイント読み込み時に消去します。
- **補充と確認用設定**：HP・スタミナの全回復、マガジン・予備弾の補充、無敵・無限弾。無敵・無限弾は保存されず、新規開始・チェックポイント読み込み時にOFFへ戻ります。有効な間はプレイ画面に表示します。
- **テスト位置5枠**：現在位置と向きを登録して戻れます。床への補正は切り替え可能です。HP・所持品・敵の状態は移動操作で変更しません。ステージの移動・拡縮後は古い位置を使わず再登録します。

範囲・射線の表示と登録位置は「Debug設定を保存」で既存の `Data/Save/debug_graphics.json` に保存できます。通常の進行保存とは別で、無敵・無限弾や射撃履歴は保存しません。

## 敵の索敵と追跡

- 索敵範囲にいても、ステージの壁やドアで胴・頭への視線が遮られる場合は発見しません。視線判定は敵ごとに0.1秒間隔で行います。
- 視認中は追跡し、見失うと最後に見えた位置を最大3秒だけ捜索します。隠れたプレイヤーの現在位置を追跡には使用しません。
- 最後に見た場所へ到着すると停止し、再発見できなければ待機に戻ります。移動要求に対してほぼ進めない状態が0.75秒続いた場合も停止します。
- 同じ通れない位置へ毎フレーム再突進せず、相手の移動や見失った後の再発見で追跡を再試行します。移動時もドアの当たり判定を使います。
- Debugの「戦闘・位置」で視認、捜索残り時間、行き詰まりを確認できます。範囲表示をONにすると視線と最後に見た位置も描画します。
